# SetCoffee — Coffee E-commerce Website

A responsive coffee e-commerce website built with **Next.js, React and Tailwind CSS**, featuring product browsing, filtering, sorting and cart functionality.

🔗 **Live Demo:** https://setcoffee-shop.vercel.app/

## Preview

![SetCoffee Preview](./public/images/projects/coffeeecommerce.png)

## Features

* Responsive design across different screen sizes
* Product search, filtering and sorting
* Filters by category, origin, roast, process, price and availability
* Shopping cart with quantity controls
* Best-seller functionality
* Similar product suggestions when no exact matches are found
* Dark and light theme
* Animations and interactive UI elements

## Tech Stack

**Next.js · React · JavaScript · Tailwind CSS · Framer Motion · Embla Carousel**

## Run Locally

```bash
git clone https://github.com/delaramfarzad9/coffee-e-commerce.git
cd coffee-e-commerce
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.
